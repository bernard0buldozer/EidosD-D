## Проверки Тильзита

1. Новый лист: данные Тильзита, 10 блоков, пустые неподтверждённые поля, сетка без перекрытий.
2. Все три стойки немедленно меняют защиту и сохраняются после reload.
3. Урон и лечение ограничены, прямое HP редактируется; отрицательный, дробный и неверный ввод заблокирован.
4. Модификаторы вычисляются из значений; проверки, преимущество и помеха показывают реальные грани и правильный итог.
5. Неизвестный бонус навыка не выдуман; введённый полный бонус используется без дополнительных надбавок.
6. Все семь типов, включая d100, поддерживают количество, модификатор и сохранённую историю.
7. Инвентарь добавляется, редактируется, раскрывается и удаляется; заметки и история персонажа сохраняются.
8. Редактируемая атака разделяет попадание и урон; формулы не исполняются как код.
9. Раскрываемые способности сохраняют описание, условия и явно заданный счётчик ресурса.
10. Перемещение мышью работает за выделенную ручку; сетка остаётся без перекрытий.
11. Размеры, порядок и свёрнутое состояние переживают reload; доступно перемещение клавиатурой.
12. Сброс раскладки не сбрасывает HP, предметы, заметки, историю или механику.
13. Шесть ширин: от 1440 до 320 px, вертикальная мобильная раскладка и отсутствие горизонтального скролла.
14. Проверка характеристики доступна на телефоне и не двигает блок в игровом режиме.
15. Настоящие touch-события перемещают и растягивают блоки на телефоне без горизонтального скролла.
16. Существующая v2 запись сохраняет имя, HP, заметки и расход действий; независимый модификатор мигрирует в вычисляемый.
17. Повреждённая запись восстанавливает лист; недоступное хранилище сообщает об ошибке и допускает игру во вкладке.

1. Смарчок: исходные характеристики, 1 HP самого гриба и незаданные параметры Туши.
2. Все основные поля редактируются; здоровье выше 12 и изменения переживают reload.
3. Способности 1 / 2 / 3 Мицелия списывают точную стоимость.
4. Нехватка ресурса явно показана; действие заблокировано и запас не списан.
5. Регенерация без кубиков: лечит до максимума и списывает только 9 фактических HP.
6. Мицелиальное поле: ручной вклад X без выдуманного дебаффа.
7. Хранилище: создание, количество, описание, заметка, категория, экипировка, поиск и сохранение.
8. Редактирование и удаление предмета.
9. Трекер тел: ручная добыча, история переработки и блокировка повторного использования.
10. Поднятие стоит 5: выбирает целое тело или создаёт новую запись нежити; переработанное тело недоступно.
11. Журнал: все категории, NPC со статусом и знакомством, заметки и сохранение.
12. Связи доступны отдельно; запись редактируется и удаляется.
13. Редактируемые навыки и владения без скрытого бонуса.
14. Все шесть проверок используют реальные 3D d20 и текущий модификатор.
15. Проверка навыка использует тот же физический движок.
16. Свободный смешанный пул всех шести типов: 7 физических кубиков, столкновения и корректная сумма.
17. История хранит время, пул, грани и итог; очищается.
18. Портрет загружается, кадрируется, сохраняется и заменяется оригиналом.
19. Тильзит сохраняет максимальное HP, вычисляет модификатор Силы и восстанавливает выбор персонажа.
20. Тильзит: стойки, простая помеха, текущий модификатор, сохранение действий и бесплатная смена после толчка.
21. Воин: парирование 20, критический ответ, смена, новый раунд и одно добивание без цепочки.
22. Прикрытие расходует реакцию и даёт бесплатную смену.
23. Простой d20 парирования Тильзита не добавляет неизвестный модификатор.
24. Переключение изолирует данные; подтверждённый сброс меняет только выбранного персонажа.
25. Оба листа без горизонтального переполнения на 1440 / 1024 / 768 / 390 / 320 px.
26. Телефон: настоящий 3D d20, 2d6, очистка выбора и быстрое удаление кубиков.
27. Окна закрываются Escape и возвращают фокус.
28. Без WebGL показана честная ошибка; случайный 2D результат не создаётся.
29. Данные переживают полное закрытие и повторный запуск браузера.
30. Повреждённое и недоступное хранилище не мешает работе листа.

## Повторение

```sh
npm ci --ignore-scripts --cache /workspace/.npm-cache
npm run typecheck
npm test
npm run build -- --base=/EidosD-D/
npm run test:browser
```

Без `EIDOS_TEST_URL` браузерные сценарии запускают и останавливают собственные Vite-серверы 4182 и 4179. Для готовой сборки задайте `EIDOS_TEST_URL` с URL статического HTTP-сервера и правильным подпутём. При публикации используется содержимое сборки вместе с `.nojekyll` в существующей gh-pages; исходники сохраняются в main без force push.

Артефакты игнорируются Git: `artifacts/tilzit-browser-results.json`, `artifacts/browser-results.json`, `tilzit-desktop.png`, `tilzit-390.png`, `tilzit-320.png`, `smarchok-*.png`, `warrior-*.png` и изображения реальных 3D-бросков Смарчка.

## Границы результата

Утверждённые изображения Тильзита и трёх стоек, подтверждённая предыстория, полные бонусы его навыков и типы урона оружия отсутствуют в доступных материалах. Для них есть явно обозначенные редактируемые поля и место портрета; содержимое не выдумывается. Критический урон и сложности существующих боевых проверок по-прежнему определяет мастер.

Тильзит использует простые равномерные броски без физики и WebGL. Смарчок сохраняет прежний реальный 3D-движок: браузерный тест действительно бросает его кубики через WebGL / Ammo с SwiftShader и проверяет фактическую арифметику. RNG в браузерных сценариях не подменяется; синтетические RNG-входы применены только в unit-тестах чистой логики.

Vite предупреждает о крупных chunks Babylon.js; сборка успешна, движок загружается при 3D-бросках Смарчка. Статичное представление Тильзита имеет интерфейс событий будущей анимации; риггинг, имитация движения портрета и новая внешность не подключены.

Ранее выполненный axe-аудит версии со Смарчком не является аудитом новой страницы Тильзита. В текущем этапе проверены клавиатурные ручки, native dialogs, Escape, именованные поля, focus и мобильные касания; полной сертификации WCAG не заявляется.

Публичный HTTPS-сайт недоступен для прямой проверки из этой среды из-за запрета CONNECT облачного прокси. Публикация проверяется отдельно по публичному статусу конкретного запуска GitHub Pages; локальные функциональные проверки не выдаются за внешний браузерный аудит.

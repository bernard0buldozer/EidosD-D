## Браузерные сценарии

1. Смарчок: исходные характеристики, 1 HP самого гриба и незаданные параметры Туши.
2. Все основные поля редактируются; здоровье выше 12 и изменения переживают reload.
3. Способности 1 / 2 / 3 Мицелия списывают точную стоимость.
4. Нехватка ресурса явно показана; действие заблокировано и запас не списан.
5. Регенерация без кубиков: лечит до максимума и списывает только 9 фактических HP.
6. Мицелиальное поле: ручной вклад X без выдуманного дебаффа.
7. Хранилище: создание, количество, описание, заметка, категория, экипировка, поиск и сохранение.
8. Редактирование и удаление предмета.
9. Трекер тел: ручная добыча, история переработки и блокировка повторного использования.
10. Поднятие стоит 5: выбирает целое тело или создаёт новую запись нежити; переработанное тело недоступно.
11. Журнал: все категории, NPC со статусом и знакомством, заметки и сохранение.
12. Связи доступны отдельно; запись редактируется и удаляется.
13. Редактируемые навыки и владения без скрытого бонуса.
14. Все шесть проверок используют реальные 3D d20 и текущий модификатор.
15. Проверка навыка использует тот же физический движок.
16. Свободный смешанный пул всех шести типов: 7 физических кубиков, столкновения и корректная сумма.
17. История хранит время, пул, грани и итог; очищается.
18. Портрет загружается, кадрируется, сохраняется и заменяется оригиналом.
19. Воин сохранён: максимальное HP и текущая Сила редактируются; выбранный персонаж восстанавливается.
20. Стойки, физическая помеха, текущий модификатор атаки и урона, сохранение действий и бесплатная смена после толчка.
21. Воин: парирование 20, критический ответ, смена, новый раунд и одно добивание без цепочки.
22. Прикрытие расходует реакцию и даёт бесплатную смену.
23. Физический d20 парирования не добавляет неизвестный модификатор.
24. Переключение изолирует данные; подтверждённый сброс меняет только выбранного персонажа.
25. Оба листа без горизонтального переполнения на 1440 / 1024 / 768 / 390 / 320 px.
26. Телефон: настоящий 3D d20, 2d6, очистка выбора и быстрое удаление кубиков.
27. Окна закрываются Escape и возвращают фокус.
28. Без WebGL показана честная ошибка; случайный 2D результат не создаётся.
29. Данные переживают полное закрытие и повторный запуск браузера.
30. Повреждённое и недоступное хранилище не мешает работе листа.

Браузерные тесты используют настоящий WebGL / Ammo (SwiftShader в тестовой среде). RNG и результаты физических кубиков не подменяются. Проверяются законные грани, соответствие пула, помеха и арифметика из фактических результатов. Unit-тесты создают синтетические входные броски для чистой проверки правил; они не заменяют физику в приложении.

Нехватка ресурса и недопустимая переработка не изменяют данные. Переработанное тело нельзя поднять или переработать снова. Регенерация не создаёт броска и списывает только фактическое лечение. Проверка браузера с WebGL, отключённым в изолированном профиле, подтверждает явную ошибку без фиктивного результата.

Окна работают с Escape и возвратом фокуса. Кнопка сброса дополнительно проверена обычным кликом на 1440 и 320 px; лоток больше не перекрывает её. Добавленный девятнадцатый навык не создаёт третью колонку.

## Повторение

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
npm run build
npm run test:browser
```

Для проверки подпути Pages соберите с `--base=/EidosD-D/`, поднимите статический HTTP server с этим путём и задайте `EIDOS_TEST_URL`. Браузерные тесты используют изолированные профили и не изменяют данные игрока. Артефакты сохраняются в игнорируемый `artifacts/`: `browser-results.json`, `accessibility-v2.json`, `contrast-flat-v2.json`, `migration.json`, `smarchok-*.png`, `warrior-*.png`, `physical-mixed-dice.png`, `mobile-physical-d20.png`.

## Публикация и ограничения

Исходники отправляются в существующую main, статическая сборка — в существующую gh-pages, без force push. Параметры HP / Защиты / Скорости Туши, уровень и запас / максимум Мицелия изначально не заданы в референсе и оставлены пустыми. Бонус, урон и тип удара Туши тоже не заданы; лист предлагает свободный лоток вместо выдуманной формулы.

Формулы критического урона, сложность парирования / толчка, дополнительный бонус атаки Воина, точные дебаффы и таблица добычи Мицелия не придумываются. Владения и навыки задаются явно.

Публичный адрес GitHub Pages нельзя проверить из текущего облака: HTTPS proxy отклоняет CONNECT к `bernard0buldozer.github.io` с 403. Это ограничение исходящего доступа среды, а не ответ сайта. Успешное обновление Git-ветки и локальная production-проверка не выдаются за проверку внешнего URL.
